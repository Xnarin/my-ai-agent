### 한국어 문서 기반 RAG Agent 구현 실습

제공된 PDF를 검색하여 근거와 함께 답하는 RAG Agent를 구현하세요.

### 제공 데이터

실습 폴더의 `data/` 아래에 금융·공공·의료·법률·커머스 PDF가 있습니다.

### 필수 구현

| 기능 | 요구사항 |
|---|---|
| 문서 처리 | PDF를 페이지별로 읽고 청킹·임베딩한다. |
| 검색 | 검색어를 받아 상위 `k`개 청크와 ID·출처를 반환하는 도구를 만든다. |
| 답변 | 검색 근거로 한국어 답변을 작성하고 파일명과 페이지를 표시한다. |
| 근거 판단 | 검색 결과로 질문에 답할 수 있는지 판단한다. |
| 재검색·종료 | 근거가 부족하면 검색어를 바꾼다. 최초 검색을 포함해 최대 3회 검색하고, 계속 부족하면 답변을 보류한다. |
| 실행 결과 저장 | 질문, 답변, 검색한 청크 ID와 근거 내용, 실행 시간 등을 DB 또는 JSON 파일에 저장한다. |

### 평가

**골든셋 구성**

[golden_set.csv](data/golden_set.csv)의 형식과 예시를 참고해 골든셋을 직접 작성하세요. 질문, 기준 답변, 근거 구절, 파일명과 페이지를 기록하고 PDF 원문과 대조해 검수하세요. 골든셋은 검색 DB에 넣지 마세요.

**비교 실험**

| 비교 대상 | 실험 조건 |
|---|---|
| 청킹 | 기본 RAG에서 청크 크기·겹침·분할 방식 중 한 가지를 바꿔 2가지 이상 비교한다. 검색 방식은 고정한다. |
| 검색 | 기본 RAG에서 벡터 검색, BM25, Hybrid Search, MMR 중 2가지 이상을 비교한다. 청킹은 고정한다. |
| 기본 RAG와 Agent | 선택한 설정으로 한 번 검색하는 기본 RAG와 재검색하는 Agent를 비교한다. |

**평가 지표**

검색 정확도, 답변 품질, 응답 시간 등 다양한 관점에서 실습에 적합한 평가 지표를 직접 선정하세요.

비교 결과와 최종 설정의 선택 이유, 실패 사례와 개선점을 정리하세요.

### 제출물

- 구현 코드와 실행 방법
- 직접 작성하고 검수한 골든셋
- 평가 결과와 개선점
