# 가상 금융 에이전트

Gemini 기반으로 계좌·이체·카드 업무를 처리하는 CLI 예제입니다. 가상 데이터를 사용합니다.

## 실행 방법

`.env` 파일에 Gemini API 키를 입력합니다.

```dotenv
GEMINI_API_KEY=발급받은_API_키
```

터미널에서 프로젝트 루트를 기준으로 예제 폴더로 이동한 뒤, 의존성을 설치하고 실행합니다. uv가 설치되어 있어야 합니다.

```bash
cd financial_agent_example
uv sync
uv run main.py
```

실행 후 원하는 업무를 입력합니다. 
승인 요청이 나오면 `승인` 또는 `거절`을 입력하고, 종료하려면 `/exit`를 입력합니다.

## 주요 기능

- 요청에 따라 이체·카드 담당 에이전트로 업무 분배
- 이체·카드 변경 전 사용자 승인

### 계좌 기능

- 계좌 목록과 잔액 조회
- 본인·타인 계좌로 이체
- 기간·금액·유형별 거래내역 조회

### 카드 기능

- 카드 목록과 상태 조회
- 카드 분실신고 및 분실신고 취소
