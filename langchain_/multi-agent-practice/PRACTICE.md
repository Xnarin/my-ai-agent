### 멀티 에이전트 종합 실습

사용자의 요청에 따라 조사·기획·검토를 수행하는 여러 에이전트를 구현하세요.

역할별 에이전트를 구현하고, 사용자 요청에 필요한 에이전트를 선택하거나 조합하는 범용 기획 시스템을 완성하세요. 에이전트의 조합과 실행 순서는 자유롭게 설계하세요.

### 구현할 기능

| 기능 | 요구사항 |
| --- | --- |
| 조사 | 사용자 요청에 필요한 정보를 여러 관점에서 조사하고 핵심 내용을 종합한다. |
| 기획 | 사용자 요청과 주어진 조건을 바탕으로 목표를 달성하기 위한 구체적인 실행 계획을 수립한다. |
| 검토 | 사용자가 제공하거나 다른 에이전트가 작성한 결과의 요구사항 충족 여부, 실현 가능성, 일관성과 누락된 내용을 확인하고 개선한다. |

### 필수 조건

- 조사·기획·검토 역할을 담당하는 에이전트를 구현하세요.
- 사용자 요청에 따라 필요한 에이전트를 선택하여 실행하세요.
- 실제 실행한 에이전트의 이름과 호출 순서를 확인할 수 있도록 콘솔에 출력하세요.
- 복합 요청에서는 앞 단계의 결과를 필요한 다음 에이전트에 전달하고 활용하세요. 조사·기획·검토를 모두 요청한 경우, 기획은 조사 결과를 반영하고 검토는 작성된 계획을 대상으로 수행하며 최종 제안서는 검토에 따른 개선 사항을 반영해야 합니다.
- `while` 문으로 사용자의 요청을 반복해서 입력받고, 같은 실행 세션의 이전 대화 내용을 기억하여 후속 요청에 반영하세요.

특정 패턴이나 Tool 사용은 필수가 아닙니다. 분기와 실행 순서는 자유롭게 구현하세요. 외부 검색 도구와 별도 사용자 인터페이스는 선택 사항입니다. 별도 자료 없이도 실행할 수 있도록 모델의 지식과 명시적인 가정을 바탕으로 구현하세요.

### 예시 시나리오

검증 예시는 대학가에서 예산 5천만 원, 운영 인력 2명으로 음식점을 창업하는 상황입니다. 업종은 분석 결과에 따라 선택할 수 있습니다.

예시에 주어지지 않은 고객 특성, 임대료, 원가 등은 가정으로 표시하세요. 추정한 수치를 실제 조사 결과처럼 표현하지 마세요. 같은 가정이 필요한 경우 일관되게 사용하세요.

### 검증할 요청

| 요청 | 기대하는 에이전트 |
| --- | --- |
| 실행 계획은 작성하지 말고, 대학가에서 운영 인력 2명으로 시작할 만한 음식점 업종 세 가지를 고객 특성과 메뉴 구성 관점에서 비교해줘. | 조사 |
| 추가 조사 없이, 대학가에서 예산 5천만 원, 인력 2명으로 운영할 덮밥집의 메뉴·가격·운영·홍보 계획을 세워줘. | 기획 |
| 다음 창업 초안의 문제를 확인하고 현실적으로 개선해줘: 대학가에서 예산 5천만 원, 인력 2명으로 메뉴 30종을 모두 직접 조리하고 매일 24시간 영업한다. | 검토 |
| 대학가에서 예산 5천만 원, 인력 2명으로 음식점을 창업하려고 한다. 고객층과 적합한 업종을 조사하고, 실행 계획을 세운 뒤 계획을 검토해 최종 제안서를 작성해줘. | 조사, 기획, 검토 |

### 대화 기억 검증

아래 요청을 같은 실행 세션에서 이어서 입력하세요.

- 첫 요청: `예산 5천만 원, 인력 2명으로 덮밥집 운영 계획을 세워줘.`
- 후속 요청: `방금 계획에서 영업시간만 오후 10시까지로 바꿔줘.`
- 기대 결과: 후속 요청에서 다시 말하지 않은 예산·인력·업종과 앞선 계획의 내용을 유지한다.
