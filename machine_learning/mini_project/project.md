# **금융 데이터 머신러닝·딥러닝 미니 프로젝트**

### **프로젝트 개요**

**금융 데이터로 신용위험을 예측하거나 사기 거래를 탐지하는 모델을 구현한다. 여러 모델과 설정을 비교하고, 결과를 바탕으로 모델의 성능과 한계를 설명한다.**

### **제출물**

| **제출물** | **포함할 내용** |
| --- | --- |
| **실행 코드** | **데이터 탐색·분할·전처리·모델 학습·평가 코드** |
| **실행 안내(README)** | **실행 환경과 패키지 설치 방법, 데이터 준비 방법, 코드 실행 순서** |
| **실험 기록** | **초기 계획, 실험별 설정과 결과 비교표, 최종 모델 선택 이유와 테스트 결과, 예측 사례 분석** |
| **회고** | **배운 점, 어려웠던 점과 해결 과정, 프로젝트의 한계와 개선 방향** |

**실험 기록의 문서 구성과 회고 형식은 자유롭게 정하고, 실험 과정과 결과가 드러나도록 작성한다. 노트북은 새 커널에서 처음부터 실행해 확인하고, 실행하지 못한 부분은 명시한다.**

### **과제 선택**

**아래 두 과제 중 하나를 선택한다. 제공 노트북에는 데이터 로딩 코드와 항목 설명이 있으며, 데이터 탐색·전처리·학습·평가는 직접 구현한다.**

### **선택과제: 신용평가**

**UCI Default of Credit Card Clients의 고객 30,000명에 대한 신용한도·상환 상태·청구액·납부액 등으로 다음 달 연체 여부를 예측한다. 한 행은 기존 카드 고객 한 명이며, 정답 `Y`는 정상 0·연체 1이다.**

**데이터 로딩 코드는 `credit_scroing.ipynb`에 제공된다. `X1`~`X23`의 의미와 월별 기록을 참고해 입력을 구성할 수 있다. `ID`는 고객 식별용으로 활용한다.**

**고객의 다음 달 연체 여부를 예측하는 분류 모델 등을 활용할 수 있다.**

### **선택과제: 사기 거래 탐지**

**BankSim의 결제 정보로 사기 거래를 탐지한다. 은행 거래 집계 자료를 바탕으로 생성한 합성 데이터이며, 594,643행·10열로 구성된다. 한 행은 거래 한 건이고, 정답 `fraud`는 정상 0·사기 1이다.**

**데이터 로딩 코드는 `fraud_detect.ipynb`에 제공된다. 금액·업종·고객 정보 등을 입력으로 활용할 수 있다.**

**정상·사기를 구분하는 분류 모델이나, 정상 패턴에서 벗어난 거래를 찾는 이상치 탐지 모델 등을 활용할 수 있다.**


### **공통 수행 내용**

- **데이터의 자료형·결측값·중복·정답 비율 등을 살펴보고 입력과 전처리를 정한다.**
- **학습·검증·테스트 데이터를 나누고, 분할 비율·난수 시드·클래스 비율 유지 여부를 기록한다. 전처리 기준은 학습 데이터에서 구해 검증·테스트에 동일하게 적용한다.**
- **문제에 맞는 머신러닝·딥러닝 모델을 자유롭게 선택해 여러 모델의 결과를 비교하고, 선택한 모델의 특징과 적용 이유를 설명한다. XGBoost, LightGBM 등 수업에서 다룬 방법 외의 모델도 활용할 수 있다.**
- **하이퍼파라미터 등을 변경하며 실험하고, 변경한 설정과 결과를 기록한다.**
- **같은 검증 데이터에서 정밀도·재현율·F1·혼동행렬·ROC-AUC·PR 곡선 등 문제에 맞는 지표와 방법을 선택해 비교한다.**
- **검증 결과로 최종 모델과 설정을 선택한 뒤 테스트 데이터에서 평가한다.**
- **성능 변화와 잘 맞힌·틀린 사례 등을 분석하고, 최종 선택 이유와 개선 방향을 설명한다. 성능이 낮아진 실험도 분석에 활용할 수 있다.**

## 진행·테스트 기록 (2026-11-25)

**선택 과제: 신용평가.** 데이터가 30,000행으로 작아 여러 모델을 빨리 비교할 수 있고, UCI에서 인증 없이 받을 수 있다. 코드는 제공된 `credit_scroing.ipynb`의 로딩 셀을 그대로 두고 그 뒤에 이어 붙였다.
