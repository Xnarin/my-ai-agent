## 가계부 에이전트 만들기 미니 프로젝트
#### AI Agent 과정 교육생 김나린 / 프로젝트 기간 : 2026-08-28 ~ 2026-08-31

### 1. 프로젝트 실행
```
main.py를 실행시키고 질문(input)을 입력한다.
예시 질문은 주석으로 표기해 놓았다.
종료를 원할시 q, 또는 quit, 종료를 입력하면 된다.
```

### 2. 파일 구성
- ```model.py```
  
  데이터의 형식을 정의한 Transaction Pydantic 모델

- ```storage.py```
  
  TRANSACTIONS, BUDGETS를 보관하고 JSON 파일을 불러오거나 저장한다

- ```services.py```
  
  거래 등록, 거래 검색, 수정, 예산 설정, 예산 확인, 월별 docs 보고서 생성 같은 실제 기능 함수

- ```tools.py```
  
  Gemini에게 주는 도구 schema와, TOOLS, TOOL_FUNCTIONS


- ```agent.py```
  
  Gemini 연결. SYSTEM_INSTRUCTION, run_agent()

- ```main.py```
  
  메인 실행 파일 테스트용

- transactions_2026_04_to_08.json
  
  4~8월 거래 내역과 월별 카테고리 예산을 저장한 데이터 파일


### 3. 구현 기능
- 수입 및 지출 등록

- 거래 내역 검색 (날짜, 카테고리, 설명으로 검색)

- 기존 거래 수정 (금액, 카테고리, 설명, 날짜 등을 변경)

- 월별 카테고리별 예산 설정

- 예산 현황 확인 (예산, 실제 지출, 남은 예산 확인)

- 거래 목록과 카테고리별 예산 현황을 .docx로 저장

- JSON 데이터 영구 저장으로 수정이 JSON에 저장되어 커널이 종료되어도 내용이 보존됨.
