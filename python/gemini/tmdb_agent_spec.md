# TMDB 영화 정보 에이전트 명세

### 간결 명세

Gemini Function Calling과 TMDB API를 사용해 사용자의 자연어 질문에 영화 정보로 답하는 에이전트를 만든다.

- Gemini는 질문에 필요한 조회를 판단하고, 필요한 경우 여러 조회를 이어서 수행한다.
- 조회한 TMDB 데이터를 바탕으로 사용자에게 자연어로 답한다.
- 영화 목록을 조회할 때는 최소 2페이지 이상을 비동기로 동시에 요청한다.(선택)

예시는 다음과 같다.

- “현재 상영 중인 영화 10개를 알려줘.”
- “인기 영화 목록에서 평점이 가장 높은 영화의 줄거리를 알려줘.”
- “인셉션을 검색해서 개봉일과 평점을 알려줘.”


### 상세 명세

### 목표

사용자가 자연어로 영화에 관해 질문하면 Gemini가 필요한 TMDB API를 호출하고, 조회 결과를 이해하기 쉬운 자연어로 정리해 응답한다.

예시는 다음과 같다.

- “현재 상영 중인 영화 10개를 알려줘.”
- “인기 영화 목록에서 평점이 가장 높은 영화의 줄거리를 알려줘.”
- “인셉션을 검색해서 개봉일과 평점을 알려줘.”

### 제공할 Function

| Function | 주요 입력 | 역할 |
|---|---|---|
| `get_movie_list` | 목록 종류, 페이지 수 | 인기, 현재 상영, 평점순, 개봉 예정 영화 등의 목록을 조회한다. 목록은 최소 2페이지 이상 조회한다. |
| `get_movie_detail` | 영화 ID | 목록이나 검색 결과에서 얻은 ID로 영화의 상세 정보를 조회한다. |
| `search_movies` | 검색어, 페이지 | 제목 등의 검색어로 영화를 찾는다. |
| `get_top_rated_movies` | 목록 종류, 페이지 수, 결과 수, 최소 평가 수 | 여러 페이지를 조회한 뒤 평점과 평가 수를 기준으로 상위 영화를 선별한다. |

Function의 이름과 입력 구조는 구현 과정에서 조정할 수 있다.

### 기능 요구사항

- 인기, 현재 상영, 평점순, 개봉 예정 영화 등의 목록을 조회할 수 있다.
- 목록을 조회할 때는 최소 2페이지 이상을 요청한다.
- 목록이나 검색 결과에서 얻은 영화 ID로 상세 정보를 조회할 수 있다.
- 제목 등의 검색어로 영화를 찾을 수 있다.
- 조회 결과만으로 답변이 부족하면 추가 조회를 이어서 수행할 수 있다.

조회 결과는 Gemini에 다시 전달하며, Gemini는 필요한 정보를 모두 얻은 뒤 최종 답변을 생성한다.

### 비동기 목록 조회(선택)

목록은 최소 2페이지 이상 조회한다. 각 페이지를 순서대로 기다리지 않고 페이지별 요청 코루틴을 만들어 `asyncio.gather()`로 함께 실행한다.

```python
pages = await asyncio.gather(*page_requests)
```

각 페이지의 `results`를 페이지 순서대로 합쳐 하나의 영화 목록으로 반환한다.

### 응답 기준

- TMDB API의 원본 JSON을 그대로 출력하지 않는다.
- 사용자의 질문에 필요한 정보만 자연어로 정리한다.
- 영화 제목, 개봉일, 평점, 줄거리 등 질문과 관련된 필드를 사용한다.
- 검색 결과가 없으면 찾지 못했다는 사실을 알린다.
- API 호출에 실패하면 임의의 영화 정보를 만들지 않고 오류를 안내한다.

### 완료 기준

- 자연어 질문에 따라 필요한 TMDB API가 호출된다.
- 목록과 검색 결과에서 얻은 영화 ID로 상세 조회를 이어서 수행할 수 있다.
- 최종 응답은 조회한 영화 정보를 바탕으로 자연어로 생성된다.
